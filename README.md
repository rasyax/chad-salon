# Chad Salon - Beauty Salon Booking System ✨

Chad Salon adalah aplikasi manajemen dan reservasi (booking) salon kecantikan berbasis web. Dibangun menggunakan kerangka kerja **Laravel** dan **Filament**, aplikasi ini dirancang untuk memudahkan pemilik salon dalam mengelola jadwal, layanan, staf, dan transaksi secara efisien melalui *dashboard* admin yang modern, sekaligus memudahkan pelanggan untuk melakukan *booking*.

## 🚀 Fitur Utama

- **Manajemen Reservasi (Booking):** Penjadwalan cerdas dengan kalkulasi durasi otomatis untuk menghindari bentrok jadwal (*double booking*).
- **Manajemen Layanan & Kategori:** Mengelompokkan jenis perawatan dan menetapkan harga serta estimasi waktu.
- **Manajemen Staf & Terapis:** Memetakan staf dengan keahlian layanan tertentu.
- **Role-Based Access Control:** Hak akses yang berbeda untuk Admin (Pemilik), Staf, dan Pelanggan.
- **Pencatatan Pembayaran:** Pelacakan status pembayaran (Pending, Paid, Failed) dan metode pembayaran.
- **Dashboard Admin Interaktif:** Dibangun dengan Filament v3, menyajikan antarmuka yang cepat, responsif, dan mudah digunakan.

## 🛠️ Tech Stack

- **Framework:** Laravel (v10 / v11)
- **Admin Panel:** FilamentPHP v3
- **Database:** MySQL / MariaDB
- **Frontend/Styling:** Tailwind CSS, Alpine.js
